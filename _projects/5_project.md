## About EpiCast

**EpiCast** is an epidemiological forecasting system that combines diffusion models with real-time public health data streams to predict disease outbreaks. Building on the AQDiff framework, EpiCast provides calibrated uncertainty estimates and adaptive forecast horizons for pandemic preparedness and response planning.

### Key Features

- **Diffusion-Based Forecasting**: Probabilistic predictions using state-of-the-art generative models
- **Adaptive Uncertainty**: Dynamic quantile adjustment based on real-time residual feedback
- **Multi-Disease Support**: Pre-trained on CDC influenza, COVID-19, and RSV datasets for cross-domain generalization
